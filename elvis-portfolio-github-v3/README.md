# Elvis Safary — GitHub Pages portfolio

This folder contains the same portfolio as the Lovable preview, with imagery and styling embedded in each page.

## Upload to GitHub
1. Unzip the download on your computer.
2. Open your `safary-elvis/elvisafary.github.io` repository on GitHub.
3. Choose **Add file → Upload files**. Upload `index.html`, `.nojekyll`, and all five page folders to the repository root. Do not upload the ZIP itself.
4. Commit the files.
5. Open **Settings → Pages**. Select **Deploy from a branch**, `main`, and `/ (root)`, then save.
6. Your portfolio will be available at https://safary-elvis.github.io/elvisafary.github.io/ if this is a project repository, or the address displayed by GitHub Pages.

GitHub does not display full websites inside repository README files. Use GitHub Pages for the complete design.

## Privacy
The site has no embedded CV or CV download. Request buttons open LinkedIn. The old CV PDF you supplied is already publicly accessible in your GitHub repository; remove it there if you want it private. Previously shared copies may remain accessible.

## Updates
Update the shared portfolio content in Lovable and regenerate this export before replacing the GitHub files. The two hosted sites do not synchronise automatically.
